## How to work

- **Pictures:**
  - Ask the generator for its largest size. For GPT Image 2.5 Sunburst that is `aspect_ratio` 16:9, `resolution` 4K and
    `quality` high, which gives 3840×2160.
  - Install with `tools/install-film-picture.mjs` and nothing else. Never overwrite or delete a picture; the tool archives
    the old one.
  - Nothing under 1920 wide goes into the film. Upscale with Topaz first (`topaz-image-upscale-v2`, High Fidelity V3, face
    enhancement off, crop off).
  - Never mirror a picture.
- **References:**
  - Attach them by `raw.githubusercontent.com/sigooding/scarlett-witness/<commit>/…`, pinned to a commit so the file cannot
    change under you.
  - For an edit, attach the base picture first, and start the prompt "Keep this picture exactly… change only…".
- **Depth:**
  - Read `docs/depth-camera.md`.
  - People get cut-outs (`tools/make-depth-layers.py --find-people`). Use `"cutoutDepth": "matte"` when their feet are out
    of shot.
  - Check maps with `tools/review-depth-maps.py`.
  - Watch the move with `tools/depth-frames.mjs`. Start `npx vite --port 5173` first and set
    `PLAYWRIGHT_CHROMIUM_PATH=/opt/pw-browsers/chromium`.
- **Build and test:**
  - Build with `FILM_SRC=/nonexistent node tools/build-film-story.mjs`.
  - Test with `npm run test:film-backend`, `npm run test:film-depth` and `npx tsc --noEmit -p .`.
  - Never hand-edit `src/data/nobodysWitnessFilm.ts`.
- **Record:**
  - What you spend and the generation ids: the README in the retakes folder, and `docs/film-picture-upscales-2026-10-25.json`
    for upscales.
  - A FILM.md section and a director-notes item.
- **Merge:** commit on your branch and push it. Then fast-forward `main` (`git push origin HEAD:main`) when `main` is an
  ancestor of your branch; if it isn't, merge `main` in first.
